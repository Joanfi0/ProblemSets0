`aed.ucu`. El programa muestra los valores predeterminados de distintos
atributos de instancia y el uso de una variable local.

## JVM, JRE y JDK

- **JVM (Java Virtual Machine):** máquina virtual que ejecuta el bytecode
  generado al compilar un programa Java.
- **JRE (Java Runtime Environment):** entorno necesario para ejecutar
  programas Java. Incluye la JVM y las bibliotecas de ejecución.
- **JDK (Java Development Kit):** conjunto de herramientas para desarrollar
  programas Java. Incluye el compilador `javac` y las herramientas necesarias
  para compilar y ejecutar el código.

En resumen, el JDK permite desarrollar y compilar el programa, mientras que
la JVM se encarga de ejecutar el bytecode resultante.

## Comentarios en Java

Java permite comentarios de una línea:

```java
// Este es un comentario de una línea.
```

También permite comentarios de varias líneas:

```java
/*
 * Este es un comentario
 * de varias líneas.
 */
```
